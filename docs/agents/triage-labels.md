# Triage labels

The engineering skills use five canonical triage roles. Their label strings in
this repository are:

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | The request will not be actioned |

When a skill mentions a canonical role, use the corresponding tracker label.
